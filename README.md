# adelina-site

Пустой каркас сайта на обычном PHP без фреймворка. Сейчас здесь нет контента и оформления — только структура, к которой можно наращивать страницы.

## Состав

```
public/            документ-root и единая точка входа index.php
src/               автозагрузка, Router, View
routes/web.php     карта маршрутов
templates/         layout и пустые страницы
tests/             место под будущие тесты
.github/workflows  CI: проверка composer.json и php -l
```

## Запуск с системным PHP

Требуется PHP >= 8.2. Composer нужен только для удобных скриптов, зависимостей у проекта пока нет.

```bash
composer serve
# или без Composer:
php -S 0.0.0.0:8000 -t public public/index.php
```

Проверка синтаксиса:

```bash
composer lint
```

## Запуск в песочнице Arena

В этой среде системного PHP нет. Для живого превью используется `php-cli` — PHP 8.2 в WebAssembly, подключённый как dev-зависимость:

```bash
npm install
npm run dev
```

Сервер слушает `0.0.0.0:8000`. Порт можно переопределить через `PORT=8080 npm run dev`.

`npm`-зависимость не входит в приложение и нужна только для локального запуска; на обычном сервере сайт работает через системный PHP.

## Git и автоматические коммиты

Работа ведётся на ветке `arena/75760c53-adelina`. Все изменения коммитятся и пушатся в конце каждого шага работы; отдельный `post-commit`-хук с авто-push не настраивается, чтобы не отправлять промежуточные состояния без контроля.

> Важно: запрошен отдельный GitHub-репозиторий `adelina-site`, но текущее GitHub-подключение не имеет права `createRepository` (GitHub App даёт `contents: write`, но не создание репозиториев). Пока `origin` указывает на исходный `a24415858-sketch/adelina`; после переподключения GitHub с нужным правом будет создан приватный `adelina-site`, `origin` переведён на него, а эта же ветка запушена туда.
