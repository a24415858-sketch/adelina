# Луна в знаках зодиака

PDF-буклет в голубой перламутровой палитре с спиральными перламутровыми ракушками и жемчугом: обложка и 12 страниц знаков, формат A4.

Готовый файл: `documents/Луна в знаках зодиака.pdf`.

Текст: `assets/content.json`. Слова исходного текста сохранены; нормализованы Unicode и типографские тире, выделены абзацы.

## Сборка

Требуется Python 3.11+ и системный шрифт `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf` (пакет fonts-dejavu-core в Debian). Cormorant Garamond включён с лицензией OFL.

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/make_pdf.py
```

Ракушка в `assets/spiral-shell.png` сгенерирована ИИ по референсу пользователя; версия с прозрачным фоном — `assets/spiral-shell-cutout.png`. Для повторного удаления фона: `.venv/bin/python scripts/prepare_shell.py`.

## Актуальное оформление

Фон `assets/pearl-ocean-background.jpg` сгенерирован по новому референсу: голубая вода, раскрытая перламутровая ракушка, жемчуг и аквамариновые кристаллы. Фон используется на всех страницах, под текстом — полупрозрачная светлая панель. Нумерация и ранее удалённые надписи отсутствуют. Старые изображения ракушек сохранены как предыдущие варианты и в текущую сборку не включаются.

### Последняя версия по полному референсу

Текущая сборка использует `assets/pearl-treasure-background.jpg`: насыщенная полноформатная сцена с раскрытой ракушкой, жемчугом и кристаллами, сгенерированная по референсу без интерфейса скриншота. Прежний фон и его голубая цветокоррекция больше не применяются. На обложке заголовок расположен сверху на светлой полупрозрачной панели; на остальных страницах панель сохраняет читаемость исходного текста.

### Обновление текста и вёрстки

По просьбе пользователя из всех 12 знаков удалены заключительные абзацы «Мама (жена для мужа)». Остальной текст сохранён. Высота светлой панели теперь рассчитывается по объёму текста: больше фона остаётся открытым. Заголовки центрированы, добавлены тонкий внутренний контур и небольшой жемчужный орнамент, увеличен кегль основного текста.

### Обложка без плашки

На первой странице название вписано непосредственно в изображение. Прямоугольная панель и её рамка удалены; читаемость обеспечивает плавное перламутровое свечение без резких границ. Внутренние страницы не изменены.

### Голубая палитра с сохранением яркости

К актуальному фону добавлена общая для обложки и внутренних страниц цветокоррекция: мятные и бирюзовые тона переведены в небесно-голубые, яркость слегка усилена. Розовые и золотистые перламутровые блики сохранены. Исходное изображение не изменяется; обработка воспроизводится при сборке.

## Видео-аффирмация «Муладхара — моя опора»

Для плавной подачи темп снижен до 88% без изменения высоты голоса, естественные паузы мягко продлены. Музыка не добавлена. Полный текст пользователя озвучен; короткие тематические надписи в кадре не являются дословными субтитрами.

Сборка:

```sh

.venv/bin/python scripts/make_muladhara_video.py
```

FFmpeg предоставляется пакетом `imageio-ffmpeg`. Промежуточные аудио и видеокадры сохраняются в `.cache/muladhara/` (исключена из Git).

## «Венера в знаках зодиака»

Новый PDF: `documents/Венера в знаках зодиака.pdf` — 13 страниц A4: обложка и все 12 знаков в зодиакальном порядке — от Овна до Рыб. Разделы от Рака до Рыб перенесены с 18 присланных скриншотов. По просьбе пользователя добавлены новые авторские тексты для Овна, Тельца и Близнецов в той же структуре; это не транскрипция отсутствующих слайдов. Надпись «От Рака до Рыб» удалена с обложки и из метаданных.

Текст перепечатан в `assets/venus-content.json`: «Чем цепляет», «Как выкрутить на максимум», «Как раскрывается» (тело, дом, образ) и «Что гасит магнетизм». По два исходных слайда объединены в одну страницу на знак. Скриншоты, девушка, чёрные поля и элементы интерфейса в PDF не используются.

Розово-перламутровый фон с розой, жемчугом и ракушкой сгенерирован отдельно (`assets/venus-background.jpg`). Текст в PDF выделяется и доступен для поиска; добавлены закладки по знакам. Проверены наличие всех текстовых блоков и рендеры обложки и внутренних страниц.

Сборка: `.venv/bin/python scripts/make_venus_pdf.py`.

## Приглашение на личный разбор Венеры

Стоимость указана по запросу пользователя: **1 000 ₽**. Контакты не выдуманы: призыв к записи — написать автору «ВЕНЕРА».

В макете использована предоставленная пользователем фотография (`assets/venus-consultation-portrait.jpg`), без генеративной обработки лица. Исходный текст — `assets/venus-consultation-content.json`. Оформление продолжает розово-перламутровую палитру основного буклета; сам буклет не изменён.

Сборка: `.venv/bin/python scripts/make_venus_consultation_pdf.py`. Проверены текст, цена и рендер готовой страницы.

## Единый файл о Венере — актуальная версия

Основной файл для скачивания: **`documents/Venera.pdf`**. Он объединяет обложку, все 12 знаков по порядку и завершающую страницу с портретом автора и предложением личного разбора за 1 000 ₽ — всего 14 страниц. Тексты знаков и цена сохранены, добавлены закладки.

По выбранному пользователем варианту «Нежный перламутровый образ» портрет обработан ИИ: мягкое освещение, светлая одежда и перламутровый фон. Обработанный вариант хранится в `assets/venus-consultation-portrait-pearl.png`; исходная фотография сохранена отдельно. Страница личного разбора теперь использует этот обработанный вариант, а не исходное фото.

Сборка единого файла: `.venv/bin/python scripts/make_venus_complete_pdf.py`. Скрипт сначала собирает обе части и затем объединяет их. Проверены все текстовые блоки, порядок 12 знаков, цена, число страниц и рендер страницы с фото.
