# Луна в знаках зодиака

PDF-буклет в голубой перламутровой палитре с спиральными перламутровыми ракушками и жемчугом: обложка и 12 страниц знаков, формат A4.

Готовый файл: `documents/Луна в знаках зодиака.pdf`.

Текст: `assets/content.json`. Слова исходного текста сохранены; нормализованы Unicode и типографские тире, выделены абзацы.

## Сборка

Требуется Python 3.11+ и системный шрифт `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf` (пакет fonts-dejavu-core в Debian). Cormorant Garamond включён с лицензией OFL.

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/make_pdf.py
```

Ракушка в `assets/spiral-shell.png` сгенерирована ИИ по референсу пользователя; версия с прозрачным фоном — `assets/spiral-shell-cutout.png`. Для повторного удаления фона: `.venv/bin/python scripts/prepare_shell.py`.

## Актуальное оформление

Фон `assets/pearl-ocean-background.jpg` сгенерирован по новому референсу: голубая вода, раскрытая перламутровая ракушка, жемчуг и аквамариновые кристаллы. Фон используется на всех страницах, под текстом — полупрозрачная светлая панель. Нумерация и ранее удалённые надписи отсутствуют. Старые изображения ракушек сохранены как предыдущие варианты и в текущую сборку не включаются.

### Последняя версия по полному референсу

Текущая сборка использует `assets/pearl-treasure-background.jpg`: насыщенная полноформатная сцена с раскрытой ракушкой, жемчугом и кристаллами, сгенерированная по референсу без интерфейса скриншота. Прежний фон и его голубая цветокоррекция больше не применяются. На обложке заголовок расположен сверху на светлой полупрозрачной панели; на остальных страницах панель сохраняет читаемость исходного текста.

### Обновление текста и вёрстки

По просьбе пользователя из всех 12 знаков удалены заключительные абзацы «Мама (жена для мужа)». Остальной текст сохранён. Высота светлой панели теперь рассчитывается по объёму текста: больше фона остаётся открытым. Заголовки центрированы, добавлены тонкий внутренний контур и небольшой жемчужный орнамент, увеличен кегль основного текста.
